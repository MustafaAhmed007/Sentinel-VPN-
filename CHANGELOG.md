# Changelog

## 0.1.0 — Foundation

- Sentinel-VPN Ω product identity and architecture established.
- Rust workspace created for VPN core, WFP policy, WireGuard, DNS, network monitoring, profiles, diagnostics, IPC, and service orchestration.
- Tauri + React desktop shell added.
- Go server API and P2P lease model added.
- Docker and systemd deployment definitions added.
- Threat model and security policy added.
- GitHub Actions CI added for Rust, desktop, Go, and secret checks.

This release is a **foundation release**, not a claim that native WFP enforcement and WireGuard process integration have been validated on a real Windows installation. Those are explicit release gates.
