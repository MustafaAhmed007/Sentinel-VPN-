# Support

For the fastest useful answer, include:

- Windows version
- Sentinel release/commit
- WireGuard version
- whether the problem reproduces after restart
- relevant diagnostic output with secrets removed
- exact steps to reproduce

## Where to ask

- **Bug:** use the bug report template.
- **Feature:** use the feature request template.
- **Security issue:** follow [SECURITY.md](SECURITY.md), not a public issue.
- **Architecture/documentation:** open an issue with the concrete question and evidence.

Please never post private keys, VPN credentials, IPC tokens, server secrets or full configuration files containing secrets.
