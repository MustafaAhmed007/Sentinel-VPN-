Sentinel-VPN Ω

Security-first, self-hosted WireGuard VPN for Windows. Sentinel separates the unprivileged desktop UI from a privileged Rust networking service and a self-hosted Linux VPS control plane. The design goal is simple: if the VPN is not verified, ordinary Internet traffic stays blocked.

VPN_NOT_VERIFIED → INTERNET_TRAFFIC = BLOCKED

Fail-closed VPN kill switch

Lock down the physical network before ordinary traffic is allowed. Verify the tunnel before opening the normal data path.

WireGuard on Windows

Use WireGuard as the cryptographic data plane while Sentinel owns lifecycle, policy, verification, and diagnostics.

DNS + IPv6 protection

Apply VPN DNS policy and verify routing so a tunnel process alone is never treated as proof of protection.

Self-hosted VPS

Run the control plane on Linux with Go, WireGuard, and nftables instead of depending on a mandatory hosted VPN provider.

P2P port forwarding

Allocate bounded public ports and map them through Sentinel-owned nftables NAT rules to a WireGuard peer.

Auditable architecture

Rust, Go, React, Tauri, CI, adversarial test gates, threat modeling, and an MIT-licensed repository are designed for community review.

Built for people who want control

Self-hosters, WireGuard users, Windows power users, homelab operators, privacy engineers, Linux VPS administrators, networking learners, and teams that want an extensible private-network foundation.

Security status: source-level implementation is not the same as a production security certification. Stable releases require real Windows, VPS, leak, failure-injection, sleep/wake, network-transition, installer, and P2P validation.
